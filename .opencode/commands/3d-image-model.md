---

Convert a photo to a 3D model (GLB) via external API.

**Usage:** `image-model <image>`

**Requirements:**
- API: Meshy / Tripo3D / Stability AI / Rodin
- Show progress bar during generation
- Load resulting GLB with GLTFLoader
- OrbitControls with damping + auto-rotate
- GSAP entrance animation
- Dispose on unmount
