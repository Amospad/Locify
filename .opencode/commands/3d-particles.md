Create a GPU particle system.

**Requirements:**
- THREE.Points with BufferGeometry
- Configurable count, size, color
- Use InstancedMesh if 50+ identical objects
- ACESFilmicToneMapping, SRGBColorSpace
- Dispose buffer geometries on unmount
- Pause on visibilitychange
