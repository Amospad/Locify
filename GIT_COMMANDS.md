# Comandos de Git para publicar los cambios de rediseño 3D futurista

Ejecuta estos comandos en tu terminal desde la raíz del proyecto para subir los cambios locales a la rama `main`:

```bash
# 1. Agregar todos los archivos modificados
git add .

# 2. Hacer commit con el mensaje estándar indicado
git commit -m "feat(web-cliente): implementar diseño 3D futurista y animaciones avanzadas"

# 3. Subir los cambios al repositorio remoto
git push origin main
```
